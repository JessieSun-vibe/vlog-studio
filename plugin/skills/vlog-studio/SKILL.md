# Vlog Studio

把真实生活素材剪成「自然、有趣、干净、带一点手帐感」的分享 vlog。真人和真实画面是主体；字幕、贴图、花字、音效都跟着正在说的内容走，不抢主体。

这个流程是从一支被用户评价为「剪得非常好」的酒店 room tour 提炼出来的（口播 + 现场原声混剪、横屏、双语字幕、章节标签、花字、动态表情贴图、音效、1.2 倍速）。照这个流程走，大部分决定都有现成答案；需要问用户的是画幅、口播稿、哪些原声保留，以及**渲染前的分镜确认**（第 6 步，必须等用户点头）。

## 0. 先读风格档案

风格（角标文字、字体、字号、配色、字幕顺序、音效文件、贴图目录、响度）不写死在 skill 里，放在用户自己的风格档案里：

1. 找 `~/.claude/vlog-studio/style.json`。有就用它；用户提到别的风格文件也可以。
2. 风格档案里的字体、音效、贴图路径找不到时（用户可能挪过文件夹），渲染会跳过并打印 ⚠️，用系统字体代替。看到警告要告诉用户、问新位置并更新档案，不要默默出一版缺贴图的片子。
3. **没有素材库**（档案里没有 `library`，或者那个文件夹不存在）：问用户要不要一键建立素材库：3 款可商用中文字体、128 个动态 / 静态表情贴图（按用途分好文件夹）、18 个原创音效，外加素材清单和预览页，从 Google 官方源下载约 45MB。同意后运行：
   ```bash
   python3 scripts/setup_library.py <素材库文件夹> --update-style ~/.claude/vlog-studio/style.json
   ```
   素材库建议放在用户的视频项目旁边（不要放在临时目录）。可以重复运行，断网后续传；完成后让用户用 Chrome 打开 `素材预览.html` 看看。
4. 没有档案就复制 `styles/template.json` 到那个位置，然后**问用户**几项关键偏好（角标文字、字幕中英顺序、有没有自己的字体/音效/贴纸库），填进去再开始。别人第一次用这个 skill 时就走这一步。
5. 档案里 `spec_doc` 如果指向一份风格规范文档，先读它；规范里用户确认过的规则优先于这里的默认做法。

风格档案的字段说明见 `styles/README.md`。

## 1. 了解素材和目标

**项目文件夹**：建议每支片子一个文件夹，里面分 `原始素材/`（拍的视频、照片、录音，只读不改）和 `生成素材/`（剪好的口播、成片、SRT、封面）。工作中间文件放 `生成素材/work/`。不要把成片留在临时目录或会话目录里，那里可能会被删。


```bash
uv run --with pillow python scripts/inspect_footage.py <素材文件夹> --out <工作目录>/inspect
```

它会列出每个文件的时长、分辨率、方向，给每段视频出每张都印了时间码的缩略图总表，照片转正方向。**逐张看缩略图**，记下每段几秒拍了什么、哪里糊、哪里有人脸或路人。

然后和用户确认（一次问完，别反复问）：
- **画幅**：默认跟拍摄方向走。横拍就出横屏 16:9，竖拍就出竖屏。参考视频是竖屏，不代表要把横拍素材裁成竖屏。要改画幅先问，裁竖会切掉画面，用户明确说过「要按我拍摄的角度来」。
- **视频类型**：旁白口播 + 画面 / 对镜头口播 / 纯画面（见 `references/video-types.md`）。
- **真实信息**：名字、价格、日期、评分、优缺点。字幕和口播只用用户说过的内容，不替用户编感受、结论或体验。缺了就留「【待补充】」并问。
- **参考视频**：用户给小红书/B站链接时，逐帧截图看画面包装（参见 `references/lessons.md` 的「看参考视频」）。截图听不到声音，别假装知道配乐和节奏。

## 2. 转写所有有人声的素材

```bash
uv run --with mlx-whisper python scripts/transcribe.py <工作目录> <音频或视频文件...> --prompt "专有名词，地名，店名"
```

在 Apple 芯片的 Mac 上用 mlx-whisper 本地转写，输出带词级时间的 JSON 和文字稿。**现场视频的原声也要转**：用户拍的时候常常会自己介绍、惊呼、吐槽，这些是最有「活人感」的素材。第一次运行要下载几百 MB 依赖，网速慢时先测速，必要时请用户换网络（见 lessons）。

## 3. 口播稿（旁白类）
- **旁白口播类**：还没录的，先按用户给的信息写口播稿：开头一句结论当钩子，中间用反问、转折，结尾总结加推荐。语气像跟朋友聊天，不平淡。标出你加了语气或判断的句子，让用户确认是不是她会说的话。
- 列一张「现场原声 vs 口播」对照表：现场说得自然有趣的句子用原声，口播里重复的那句删掉。让用户选。

## 4. 清理人声（口播 / 对镜口播）

```bash
python3 scripts/clean_speech.py report <转写.json> <音频>                       # 列出停顿、疑似重复、拖长的字
python3 scripts/clean_speech.py apply <音频> <cuts.json> <输出.wav>             # 按切点剪，0.01s 淡入淡出
```

- 停顿超过约 0.4s 的缩到 0.18s 左右，留一点换气。
- 同一句说了两遍，保留最后一遍说顺的。**语音识别会把重复合并成一句**：「毛巾…毛巾天鹅」可能只转出一个「毛巾天鹅」，但那个字的时间会被拉得很长。`report` 会把「一个字超过 0.6s」标出来，逐个看能量图确认，并且要切掉完整的第一遍（从这句开头切），不要只切中间。
- 说错的词，比如 Fried 说成 Fair：删掉整句，用字幕或花字补正确信息；或者请用户补录这一句。
- 剪完一定**重新转写剪辑版**，核对没有切掉字、没有残留的重复。

## 5. 搭时间线：声音为主线，画面跟着声音走

时间线是一份 JSON（格式见 `references/timeline-format.md`）。用 `scripts/timeline_tools.py` 里的函数生成，不要手算时间：

- **口播片段的起止点**用 `shared_cuts()`：前后相接的两句共用同一个切点，切在两句之间最安静的地方。不要给每句都加前后余量，余量会把上一句的尾字带进下一句开头。
- 现场原声片段（对镜口播也是这一类）：画面和声音来自同一段视频的同一时间，前面留约 0.25s、后面留约 0.35s。
- 每句字幕的时间来自转写；中文太宽（超过约 1400px）就用 `split_sub()` 按标点拆成先后两条，英文只在标点处断开。
- 同一段素材别在相邻镜头里重复用；素材不够长就用慢镜头（speed < 1），不要定格。
- 章节第一个镜头放章节标签，加切换音效；拍照或照片出现时加快门；花字弹出时加「啵」。贴图要和这句话的内容有关。
- **挑贴图和音效**：风格档案里有 `asset_catalog`（素材清单 JSON）时，先读它。每个素材都写了含义和适合的场景（如「money-face｜价格、便宜、性价比」「失败-oops｜翻车、踩雷、小缺点」），按这句话在说什么来挑。不要每个镜头都放，一个镜头最多一两个。时间线里的音效可以直接写风格档案 `sfx` 里的名字（chapter、page、photo、pop、ding、sparkle、tada、oops、whoosh…）。库里没有合适的，用 `scripts/fetch_stickers.py` 补（下载前先问用户），补完更新清单。

### 有人脸的镜头（对镜口播、自拍、合照）
```bash
uv run --with opencv-python python scripts/face_track.py <视频> <工作目录>/faces.json --fps 10
```
得到每个人脸随时间的位置（多人时从左往右编号）。然后可以：
- **跟着脸走的贴图**：贴图加 `"follow": {"track": "faces.json", "who": 1, "dx": .95, "dy": -.55, "size": .6}`，大小按脸宽算，人动贴图跟着动，还会轻轻上下浮动。比如说到「婚礼」时两人脸旁各飘一颗爱心。一句话跨了剪辑点时，后一段的同一贴图设 `"pop": false`，就不会在剪辑点重新弹出。
- **避开人脸**：花字、信息卡、静态贴图都别压在脸上。看 faces.json 里脸的位置，把东西放到画面空的一侧；花字可以单独设 `"fx": {"y": 150}`。
- **信息卡**：`"card": {"title": "10月1日 · 上海", "sub": "Oct 1 · Shanghai", "icons": [...], "x": 440, "y": 770, "at": 1.9}`，白色纸片加图标，弹出出现。日期、地点、价格这类信息只用用户给的。

## 6. 分镜确认（必须，没确认不渲染）

用户明确要求：**生成视频之前先给分镜，确认后再生成。** 第一版成片、结构性改版（换段落、加删镜头、换包装）都要走这一步；用户只是让你挪一个贴图、改一个字，可以直接改。

1. 时间线 JSON 写好后，在 timeline 里加 `"title"`（分镜标题）和 `"removed"`（剪掉了什么，比如「6.25–6.70s 停顿」「第一遍『床上摆着毛巾』」），然后：
   ```bash
   uv run --with pillow --with resvg-py python scripts/storyboard.py <timeline.json> --out <项目>/生成素材/分镜
   ```
2. 先自己看一遍样张（每个片段一张，所有贴图、花字、信息卡、跟脸贴图都画在成片里的真实位置）：有没有挡脸、挡字幕，图和这句话对不对，画面是否拍到空墙或模糊转场。有问题先改时间线再重出分镜，不要把明显的问题交给用户。
3. 把分镜给用户：
   - `storyboard.html` 发布成页面或作为文件发送（图片已内嵌）。
   - 在对话里贴 `storyboard.md` 的文字表：编号、变速后的时间、原话字幕、花字和信息卡、贴图、音效。
   - 写清楚剪掉了哪些停顿、重复、口误，以及哪些是你加的、需要确认的（加了语气的字幕、自己选的贴图）。
4. **停下来等用户确认**（用户说「可以 / 确认 / 开始做」）。用户改了什么，就改时间线、重出受影响的样张，再确认一次。
5. 确认之后才进入下一步渲染。

## 7. 渲染

```bash
uv run --with pillow --with resvg-py python scripts/render.py <timeline.json> --style ~/.claude/vlog-studio/style.json
```

输出 MP4（H.264 / AAC，−16 LUFS）和双语 SRT。每个片段单独渲染再拼接，加 `--only 3,4` 可以只重渲个别片段来试效果。需要整体变速时：

```bash
python3 scripts/speedup.py <成片.mp4> <成片.srt> 1.2     # 人声音调不变，字幕时间同步
```

## 8. 交付前自查

- 用 `uv run --with pillow python scripts/inspect_footage.py --sheet <成片> --out <目录> --step 1` 出成片缩略图总表，看每个镜头的画面是否对得上台词，有没有拍到空墙、衣柜、模糊转场、路人。
- **把成片的声音重新转写一遍**：逐句核对没有重复、没有漏句、原声都在。转写里多出来一句的地方，先看能量图，再判断是真的有声音，还是识别器重复输出了上一句。
- 响度约 −16 LUFS，没有黑帧（`ffmpeg -vf blackdetect`）。
- 字幕：加速后每秒超过 7 个字的、停留短于 0.8s 的，告诉用户。
- 每次输出新版本号（v1、v2…），不覆盖旧版本。告诉用户改了什么、核对了什么、还剩什么没做（配乐、封面、文案、署名）。

## 风格默认值（风格档案没写时用）

- 横屏 1920×1080、30fps；左上角固定角标，章节标签在它下面，换章节时从左滑入。
- 字幕：中文在上（约 51px）、英文在下（约 33px），深色半透明圆角底条，放在底部。
- 花字：圆体粗字、黄字橙描边、略倾斜，弹出时从 0 放大到 1.15 再回到 1；只在有反应的地方用。
- 口播或原声说话时，环境声压到约 12%；没有人说话的段落让现场声音出来。
- 贴图、字体、音效的授权要记清楚（见 `references/lessons.md`），发布时附上署名。
