# 三种视频类型

## A. 旁白口播 + 画面（第一支海岛酒店 room tour 就是这种）
1. 看素材、转写所有视频原声（找现场的介绍和反应）。
2. 没录口播：按用户给的信息写口播稿（钩子开头 → 反问/转折 → 总结推荐），确认后请用户录（iPhone 语音备忘录设「无损」，安静小房间，离嘴一拳半，说错了停一下从这句开头重说）。
3. 录好后：转写 → `clean_speech.py report` → 确认切点 → `apply` → 重新转写核对。
4. 列「现场原声 vs 口播」对照表让用户选；时间线以口播为主线，原声片段插在对应位置，画面跟着声音走。
5. 口播时环境声压到约 12%；没人说话时让现场声音出来（如现场弹唱）。

## B. 对镜头口播（人对着镜头说话）
1. 转写视频本身的声音。画面和声音是同一条，不能分开剪。
2. `clean_speech.py report` 找停顿、重复、口误。切点用视频时间，片段类型都是 `"audio": {"type": "clip"}`，`video.start` 和 `duration` 来自切点。
3. 跳剪很多时，相邻两刀之间可以给画面一点 1.05–1.1 倍的缩放变化（`speed` 不变，另做一个裁切），减少跳帧感；或在讲到物品、地点时插入 B-roll 画面盖住接口（这时声音仍用对镜原声，画面换成别的素材：把那段做成 `audio.type=clip` 的同一视频声音 + 另一 `video.src` 需要先抽出音频当 voiceover 用）。最简单的做法：把对镜视频的声音导出成 wav 当 `voiceover`，所有片段用 `type: vo`，画面自由选对镜或 B-roll。
4. 保留自然的笑、手势、语气；只剪空白、找词、重复和说错的。
5. 包装（花字、贴图）避开脸和手势，放在画面空的一侧。先跑 `face_track.py` 知道脸在哪。
6. 实例（婚礼邀请，21 秒自拍合照口播）：剪 3 处停顿（0.4–0.7s）→ 4 段 clip；说到「婚礼」两人脸旁各一颗跟着走的爱心；「吃好喝好」碰杯贴图；结尾挥手时叠信息卡（日期 · 地点）配 tada。整片 1.2 倍速后 16 秒。

## C. 纯画面 vlog（没有人说话）
1. 先按时间或主题排镜头，问用户想要的节奏和时长。
2. 片段用 `"audio": {"type": "ambient"}`（现场声）或 `none`，整片配 `bgm`（风格档案或用户提供；授权要清楚）。
3. 字幕改成少量「信息旁注」：地点、价格、心情，中英双语，手写感；不要每个镜头都有字。
4. 镜头切换可以卡音乐节拍，但不机械卡点。
